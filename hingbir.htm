Hingston Births from FreeBMD and GRO 1837-1900

The inclusion of the mother's maiden name in the GRO births index allows us to identify groups of children with the same parent's surnames, so in most cases they come from the same family. We can then use the facility in FreeBMD that allows us to search for potential marriages. However, the response from that search is not usually unique. Many pages in the registers include several marriages and the search only confirms that the same two family names appear on the same page. However, if the names are relatively unusual and there is only one marriage that occurs just before the children start appearing we can be reasonably sure that we have the right marriage. In several cases, however, there are multiple returns from the FreeBMD search, so we cannot be sure which is relevant. In other cases, FreeBMD returns no result. This could be because the entry has been mis-transcribed somewhere or because the bride had been married before, so the name recorded at her marriage to a Hingston was not her maiden name.

This table is derived from several sources. It is based on the FreeBMD listings of the Hingston births in England and Wales, to which I have added a column of mother's maiden names taken from the GRO's own birth index. I have then correlated them with our known Hingston trees and provided a cross-reference in the column marked "Tree link". Entries that are not already in Trees have been grouped together by mother's maiden name and are listed in "Notes" on a separate page.

In both sets of transcriptions there are many entries where Hingston has been transcribed as Kingston, but there are more errors in the GRO's own index. Where I know from other sources that there are Hingstons and I can find the relevant entry under a different spelling I will add them below.

Note that all the dates reported here are to "Quarters", (March, June, September and December) so each covers three months, and the locations refer to the registration district, and these changed with time (GenUKI has a list).

The censuses and parish registers should help us to resolve issues and assign these families to particular trees. If anyone has information about these families, please let me know.
